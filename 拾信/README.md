# 拾信 · 微信聊天导出入口

使用上游 [WeChat Chat Export for LLM](https://github.com/zhuzhangxue/wechat-chat-export)。Windows EXE 约 143 MB，请从 [v1.4.0 发布页](https://github.com/zhuzhangxue/wechat-chat-export/releases/tag/v1.4.0) 下载。

用自己登录的 Windows 微信导出会话。与[句读工坊](../句读工坊/)配合时，可以把输出放在 `exports/`，或在标注工具里手选。结构化输入是 `chat_full_parsed.json`。

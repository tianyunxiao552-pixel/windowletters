# 窗边来信

两位聊天角色，加上整理聊天和个人资料的三件本地工具。Windows 下可按需使用。

| 名字 | 用途 |
| --- | --- |
| [萤火来声](萤火来声/) | QQ 的汐见萤，支持聊天记忆、识图和日语配音。 |
| [依都夜谈](依都夜谈/) | 微信的瀬尾依都，支持接话、分层人格和北京时间 23:00 群报。 |
| [拾信](拾信/) | 微信聊天导出，提供对应的上游版本入口。 |
| [句读工坊](句读工坊/) | 标注回复上下文，整理风格样本。 |
| [自画像](自画像/) | 采集 Bangumi 公开收藏和 B 站公开动态、文章，构建 SQLite 资料库、离线查看页和人格卡参考素材。 |

QQ 与微信各有一套运行目录，面板分别使用 6185 和 6186。新部署从各模块的 README 开始。账号、密钥、聊天、个人资料、训练语料和模型资产由使用者在本地配置。

微信端有两条可选的资料来源。[拾信](拾信/)导出聊天，[句读工坊](句读工坊/)把指定示例整理成风格样本。[自画像](自画像/)把作品评分、公开发言和有出处的档案条目整理成资料库。[依都夜谈](依都夜谈/)可同时读取风格样本和资料库。
